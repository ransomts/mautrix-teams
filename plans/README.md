# Implementation plans (historical)

The files in this directory are design notes and checklists written during the
initial implementation of the bridge, before it was rewritten on top of
mautrix bridgev2. They are kept for reference only:

- They are **not** kept in sync with the code. Many describe components that no
  longer exist (for example the standalone `teams-login` CLI and the pre-bridgev2
  poller), and the checklist states do not reflect what is implemented today.
- `prompt.md` and `plan_review.md` are the prompts used to produce and review
  these plans.

The code and `CHANGELOG.md` in the repository root are the source of truth.
